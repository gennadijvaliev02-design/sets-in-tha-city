SETS IN THA CITY — готовое демо

1. Распакуй ZIP.
2. Открой index.html в обычном браузере для просмотра.
3. Для публикации загрузи index.html и всю папку assets рядом в ОТДЕЛЬНУЮ папку сайта или отдельный репозиторий GitHub Pages.
4. Не заменяй файлы другого действующего сайта.

Сборка и установка пакетов не нужны. Фото уже подключены.
Шрифты Google Fonts требуют интернета; без него используются системные шрифты.
Все ссылки выпусков открывают профиль Instagram: точные ссылки на ролики не были предоставлены.
Выпуски 006, 004, 003, 001 используют настоящие миниатюры из скриншота, кадрированные только CSS. Их качество ограничено исходным скриншотом.
Четыре крупных фото сохранены без генеративных изменений. В лайтбоксе показывается оригинал, включая значок звука на одном кадре.

Проверка: синтаксис JavaScript, логика меню/галереи в имитации DOM (без браузера), существование локальных изображений и целостность ZIP. Живой браузерный render-тест не выполнялся.
